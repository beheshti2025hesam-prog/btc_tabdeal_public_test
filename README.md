# BTC Tabdeal Public API Test

First-stage safe connectivity test.

This version:
- does NOT use Binance
- does NOT require a Tabdeal API key
- does NOT access account balances
- does NOT place orders
- does NOT trade

It only tests public Tabdeal API connectivity and checks BTCUSDT in exchangeInfo.

After this passes, the next stage will add verified Tabdeal Futures market-data handling.
