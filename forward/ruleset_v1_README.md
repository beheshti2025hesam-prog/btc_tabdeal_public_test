# Forward Ruleset v1

This is the first explicit rule layer, but it remains **DRAFT_NOT_ACTIVE**.

It establishes deterministic gates without importing historical tuning:
Data Quality → Structure → Opportunity → Confirmation → Risk → Decision.

No indicator threshold, confirmation count, weighting, stop distance, RR,
position-size rule, or win-rate target is invented here.

A future activation must supply each null policy field through a new,
versioned specification based only on a new forward design decision.

Every decision must remain explainable through contemporaneous evidence refs.
