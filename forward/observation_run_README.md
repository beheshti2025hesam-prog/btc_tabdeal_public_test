# Observation Run Record v1

Creates a one-time, append-only metadata record for an observation-only
forward run.

The record explicitly states:
- run identity;
- policy/version;
- market scope;
- source;
- observation-only mode;
- NO_TRADE_ONLY decision mode;
- execution disabled;
- historical inputs disabled.

This is a runtime evidence boundary, not a trading-performance claim.
